# CrossTwins v1.6.5-ct.6 + X4 Pro BLE 페이지 터너 (시험 빌드)

upstream CrossTwins v1.6.5-ct.6에 X4 Pro용 BLE 페이지 터너를 더한 crosspoint-reader-ko 시험 빌드입니다. 태그 끝의 7자리는 빌드한 커밋 SHA입니다.

## 바뀐 점

- X4 Pro(`x4pro`) 빌드에 BLE HID 페이지 터너가 들어갑니다. 설정에 블루투스 항목이 생기고 페어링, 페이지/챕터 이동을 X3/X4와 같은 방식으로 씁니다.
- X4 Pro는 S3 기본 Arduino SDK의 NimBLE 컨트롤러를 그대로 씁니다. USB 드라이브(TinyUSB MSC) 구성은 바뀌지 않습니다.
- X3/X4 빌드는 upstream ct.6과 같습니다. X4 Classic, Sticky, Paper Mono에는 BLE가 없습니다.

## 다운로드

| 기기 | 앱 이미지 | 전체 플래시 이미지 |
|---|---|---|
| X3 / X4 | `crosspoint-<ver>-x3-x4.bin` | `CrossPoint-<tag>-x3-x4-full.bin` |
| X4 Pro | `crosspoint-<ver>-x4pro.bin` | `CrossPoint-<tag>-x4pro-full.bin` |
| X4 Classic | `crosspoint-<ver>-x4c.bin` | `CrossPoint-<tag>-x4c-full.bin` |
| Sticky | `crosspoint-<ver>-sticky.bin` | `CrossPoint-<tag>-sticky-full.bin` |
| Paper Mono | `crosspoint-<ver>-papermono.bin` | `CrossPoint-<tag>-papermono-full.bin` |

- `-full.bin`은 0x0에 쓰는 병합 이미지(부트로더+파티션+앱)입니다. 앱 이미지는 0x10000(OTA 슬롯)이나 SD 펌웨어 업데이트에 씁니다.
- 체크섬은 `SHA256SUMS`에 있습니다.

## 주의

- 시험 빌드입니다. X4 Pro BLE는 실기기 검증 전입니다.
- 기기의 OTA는 `meat-holic/CrossTwins` 릴리스를 봅니다. 이 빌드는 OTA로 배포되지 않습니다.
- 내부 펌웨어 버전은 `1.6.5-ct.6+<SHA>`입니다.
